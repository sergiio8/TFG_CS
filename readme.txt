Motor CBR para la optimización de reglas de autómatas celulares mediante estrategias evolutivas

En cada carpeta hay readme's explicativos de cada archivo

main.py ejecuta el motor CBR para un problema determinado que debe configurarse en el archivo
main_heuristica.py resuelve varios casos determinados con una parametrización heurística creada con conocimietno experto
main_random.py resuelve los casos deseados con una parametrización aleatoria
